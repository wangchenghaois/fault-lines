# 现场速查卡

> 一页纸。演示前 10 分钟看这个就够了。完整材料见 `docs/02-路演手稿.md`。

## 演示前 10 分钟

```bash
# 1. 模型服务在本机活着吗（它会自己退出）
curl -s -m 2 http://127.0.0.1:11434/api/version || ollama serve

# 2. 预热，别让第一条回答吃满超时
node scripts/repro.mjs

# 3. 起服务
node server.mjs 4188
```

浏览器开 `http://127.0.0.1:4188/?ds=marriage`（marriage 那套的 i1→i2→i3 正好是事实→预测→价值三种断层，最适合演示）。

**兜底**：任何一步坏掉，直接双击 `歧见.html`——内置四个数据集不需要模型、不需要服务器，断层图和信念推演全都照常工作。

## 三个按钮，90 秒

| 动作 | 说什么 |
|---|---|
| 打开 marriage 集，指断层总图 | "这不是观点列表，是剖面图。蓝色条纹的事实分歧能查，橙色是价值分歧，永远不会被证据说服。" |
| 点 i1（蓝色，事实断层）→ 再点 i3（橙色，价值断层） | "同样是吵架，处理方式根本不同。现在所有产品把它们当同一件事。" |
| 点「站 A 方」 | "你选了一边，它推出你在另外两个争点上逻辑上该站哪边，以及你要付出什么代价——这条论据你无法反驳，但你的立场和它冲突。" |

## 现场喂它一段真话（3 分钟，可选）

点「导入」→ 粘 3 段立场不同的回答（空行分隔）→ 勾着「使用本地模型抽取」→ 生成。

- **3 条回答约 70 秒，4 条约 110–130 秒**。等待时不要沉默，讲这个：等待是本地推理的代价，换来的是数据不出本机——知乎内容不需要发给任何第三方。
- 如果机器上没装 Ollama：弹窗里会直接写「未检测到本机模型 —— 取消勾选即可用规则引擎」，取消勾选后 0.2 秒出结果，只是聚类粗一些。
- 分析完会跳一行提示「分析完成：N 条主张，M 个争点」。**如果它说 0 个争点**，那是回答太一致或太短——这是产品在拒绝硬凑对抗，不是失败，可以顺势讲"它宁可说没有争点，也不编一个"。

## 七个必答问题（一句话版）

**"这不就是聚类吗"** → 聚类给你分堆，歧见给你判断：这堆分歧能不能被证据解决、按什么信号裁决。类型判定和推演都是规则算的，不是模型编的。

**"直接问大模型不就行了"** → 问模型会得到一个漂亮的总结，但它会把不可解决的价值冲突写成"综合来看"。歧见的价值恰恰是拒绝综合。

**"凭什么说你在别处必须站哪边"** → 不说"必须"，说"如果前提一致"。前提标签是模型从回答里抽的，重叠计算是规则做的，冲突论据全部可见可反驳。

**"数据合规"** → 不抓取、不存储、不上传。全本地推理，零 API Key。示例数据是公开讨论的重构，不是知乎原文引用。

**"商业化"** → 现在不做。这套机制最自然的落点是社区内容产品里的"观点对照"模块。

**"一周最没做完的是什么"** → 互斥表只有约 20 组人工维护的标签，覆盖面有限；多语言没做；只有四个数据集，且都是依据公开讨论重构的。

**"为什么叫歧见"** → 分歧的"歧"，见解的"见"。也对应 geological fault——断层不是错误，是结构本身。

## 如果有人问"AI 含量在哪"

1. 论点萃取：五类主张分类 + 前提标签抽取（本机 4B 模型，`reasoning_effort:'none'` 关掉思维链）
2. 争点归并：把 N 条主张归到 2–4 个真正对立的争点上
3. 信念推演：**规则引擎**，不是模型——前提标签重叠 + 人工互斥表，所以可复现、可解释

第 3 点要主动说：**把最关键的一步交给规则而不是模型，是设计选择，不是能力不足。**
