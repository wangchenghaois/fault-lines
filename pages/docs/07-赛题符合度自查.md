# 赛题符合度自查

对照来源：赛题原文（用户提供的三大赛道说明）。自查时间：提交前。
判定口径：**「符合」= 有可运行的实物和证据；「部分」= 方向对但缺关键一环；「缺」= 没有。**

---

## 一、总判定

**原型强度足够，赛道相关性有一条硬伤。**

- 能跑、能演、能复现（386 条断言 + 真模型端到端 + 干净房间测试）→ 强于大多数"只能 PPT 演示"的作品。
- 但赛题原文写的是「借助知乎社区**内容资产**与**开放接口**」，而当前成品**两样都没真用上**：数据是重构示例，接口客户端写好了但没接进界面、也没有真实凭证验证过。

这一条如果不补，评委只要问一句"这里面哪些数据是知乎的"，就会很尴尬。

## 三、三个真缺口与补法

### 缺口 1（硬伤）：没有真用知乎的数据和接口

这是唯一可能被判"跑题"的一条。三种补法，成本递增：

| 补法 | 做法 | 成本 | 效果 |
|---|---|---|---|
| A 接真接口 | 用 Access Secret 调 `zhihu_search` + `hot_list`，把真实问题的**回答数/关注数/浏览数**引进界面 | 半天（客户端已写好） | 彻底解决，且能演示"真数据下的赛道地形" |
| B 粘贴真内容 | 让人手动粘真实高赞回答，产品负责分析 | 已有 | 数据是真的，但没有"接口"这一层，仍是半个 |
| C 只写不接 | 保留现在的 `zhihu.js`，答辩时说明"接口层已实现" | 0 | 评委大概率不接受 |

**建议 A + B 并存**：有 Key 走接口，没 Key 走粘贴，界面如实标注数据来源。这也是我一直在做的"降级路径"设计。

### 缺口 2（软伤）：大湾区 —— 已按最低成本补上

不需要硬蹭。做法就是加一个湾区垂类的示例数据集（不假、不吹）：**`gba`「跨境电商还要不要自建独立站，还是全押平台？」**

- 5 条回答 / 10 条主张 / 4 个争点，三种断层齐备（2 个事实 + 1 个价值 + 1 个预测），规格和前三集完全一致；
- 如实标注「依据公开讨论重构，非知乎原文引用」，没有声称做过任何地域调研；
- 它让"立足大湾区产业土壤"这句话有了落点，而不是空口；
- 顺带证明产品是领域无关的（同一引擎能吃任一领域），这是加分不是减分；
- 8 种「争点 × 侧」组合全部有投影和代价（`scripts/checkgba.mjs` 可复现），不会出现"点进去是空的"。

边界仍然写清楚：这证明的是「同一套机制能读另一种行业」，不是一份湾区市场研究。

### 缺口 3（答辩风险，不是缺陷）：AI 含量

第 3 层信念推演是**规则引擎**算的，不是模型生成的。这在技术评审眼里可能是减分（"这不算 AI"），也可能是加分（"可解释、可复现、不幻觉"）。

处理方式：**主动说，别等人问**。话术：

> 抽取和归并是模型做的，推演是规则做的。这是刻意的——推演如果让模型生成，它每次给的答案都不一样，用户没法追问"凭什么"。规则至少能被指着说"这张互斥表错了"，能被修正。AI 负责读，规则负责算，这个分工是设计选择。

## 四、新方向（创作者工具）在赛题里的位置

用户提出的方向：给知乎新手创作者做"赛道勘探"，帮他们看清细分领域的情况再决定深耕哪个垂类；并做成可接各家模型 API 的创作插件。

**符合度评估：**

| 维度 | 判断 |
|---|---|
| 是否解决真实痛点 | ✅ 是，且比"读长文"更刚需（新人生存问题） |
| 是否用知乎开放接口 | ✅ 天然需要（search / hot_list），**正好补上缺口 1** |
| 是否属于赛道 01 | ⚠️ 边缘。赛道 01 面向"帮助用户理解观点、发掘知识"，创作者工具偏 B 端。但可框成"帮新作者认识一个领域的知识结构"——这仍是知识发现，只是服务对象从读者换成作者 |
| "可接各模型商 API" 是不是卖点 | ❌ 不是。那是配置项，不是创新。评委不会因为支持 6 家模型加分 |

**建议的融合方式（不推翻现有工作）：**

同一个引擎，两个视角：

- **读者视角**（现有《歧见》）：这个争论为什么分成两半 → 断层图
- **作者视角**（新增）：这个领域哪里还空着 → 地形图

它们在数据上是同一份东西：活断层 = 还有读者在等一个说法；孤证区 = 薄弱但没人认真反驳的角度；沉默的多数 = 有人问没人答 = 新人的空白位；共识基线 = 入场门槛。

一句话故事：**「同一张断层图，读者看到分歧在哪，作者看到位置在哪。」**

这个融合有三个好处：不浪费一周的工作；接口数据有了真用途（不是为接而接）；叙事比单纯"读长文"或单纯"选题工具"都更完整。
