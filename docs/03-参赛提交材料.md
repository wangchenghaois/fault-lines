# 参赛提交材料 · 歧见 Fault Lines

## 基本信息

| 项 | 内容 |
|---|---|
| 作品名 | 歧见 · Fault Lines |
| 一句话 | 把一段真实讨论拆成观点断层剖面：哪些分歧是事实、哪些是价值、哪些是预测 |
| 赛道 | 01 社区 × 知识发现 |
| 形态 | 本地运行的 Web 应用（单文件可离线）+ 演示视频 |

## 一句话讲清它是什么

输入：一个知乎问题下的多条回答（内置 3 组示例，或你自己粘贴的讨论）。
输出：

1. **断层总图**——争点按性质分色：蓝=事实（可查）、橙=价值（只能投票）、紫=预测（只能等）。
2. **争点剖面**——每个争点两侧的论据、真正分歧在哪、以及"如何裁决"。
3. **信念推演**——你站一边，它推出你在其他争点上逻辑上必须站哪边，并列出你反驳不了的代价。
4. **孤证区 / 沉默的多数**——最容易被误读成普遍规律的那一条，和那些只讲经历不讲立场的人。

## 新问题（这是本作品的出发点）

市面上所有"AI 读长文"的工具，都在回答**同一个问题**：怎么把长的变短。

但知乎这类社区真正的困难不是信息不足，是**信息过载 + 类型混淆**：一条可验证的统计数据，和一句不可验证的价值主张，在页面上长得一模一样，权重也一样（都有几百个赞）。

所以歧见提的是另一个问题：

> **能不能不减少信息，而是给信息加上"类型"这一层？**

一旦加上，很多看起来无解的争论突然有了正确的处理方式——不是"谁对"，而是"这属于哪类问题、该用什么方式解决"。

## 三个机制细节（技术评审关心的地方）

### 1. 断层判定不是模型拍脑袋

每个主张先被判类型（事实/价值/预测/因果/定义）。争点的断层类型由**两侧主张的类型分布**决定：

- 两侧主体是事实主张 → `fact`，「可被证据解决」，附裁决信号；
- 出现价值主张且两侧对立 → `value`，「永远不会被证据说服」，因为证据无法裁决价值；
- 主体是预测 → `prediction`，附"观察什么信号能判胜负"。

这条规则是可解释的，不是让模型输出一个标签就完事。

### 2. 信念推演是规则算的，不是模型编的

每条主张带 `premiseTags`（如 经济决定论、观念独立变量、理性人假设、制度决定论）。代码里有一张**互斥表**（约 20 组，如 经济决定论 ↔ 观念独立变量）。

你选 A 侧 → 得到你的前提集合 → 对每个其他争点，计算哪一侧的前提与你**相容**、哪一页与你的前提**互斥** → 相容的一侧即为"逻辑上你该站的位置"；同时，与你结论冲突但前提不冲突的论据，被列为**代价**。

因为它是算的，所以你能追问"为什么"，也能看到互斥表本身错在哪。

### 3. 全本地，且有降级路径

- 默认推理后端：本机 Ollama（`qwen3.5:4b`），零 API Key。
- 没装 Ollama：自动降级到规则引擎（信号词分类 + 词重合度聚类 + 强制分侧兜底），功能完整、精度下降。
- 打包产物 `dist/歧见.html` 是**单文件**（CSS+JS 全内联），双击即可运行，无网络无依赖。

**实测数字（本机 4.2B / Q4_K_M / GTX 1650 4GB）**：探活 0.1s；单条回答抽主张 2.9–9.4s；3 条回答全流程 70–82s；4 条回答全流程约 130s；冷启动（模型首次载入显存）最多 90s、一次性；后端不通 43ms 即报错降级；同一批走规则引擎 < 0.2s。内置四个数据集是预先分析好的，切数据集瞬时。

一个我们踩到并修掉的坑：`qwen3.5:4b` 是 thinking 模型，不关思考时会把 token 全烧在思维链上、`content` 返回空（实测 32s / 1401 字推理 / 0 字正文），表现为"每次都超时然后悄悄降级"。现在请求带 `reasoning_effort:'none'`，同一任务 3.5s 返回干净 JSON；正文为空时立刻报错而不是静默降级。

对这类产品，本地不是技术洁癖：**用户贴进来的是别人的真实表达，把它上传到某台服务器去分析，本身就是一种冒犯。**

## 与赛题的对齐

| 赛题原文要求 | 本作品 |
|---|---|
| 依托知乎沉淀的海量真实问答与多元观点 | 以知乎式问答讨论为唯一输入形态；内置 3 组依据公开讨论重构的示例 |
| 用 AI 重构认知路径 | 不走"总结"路径，走"分类 + 推演"路径：认知路径是 看见断层 → 理解性质 → 定位自己 → 看见代价 |
| 帮助用户在纷繁信息中理解观点、梳理逻辑 | 争点归并 + 前提标签 + 互斥表推演，逐层可追溯 |
| 发掘有效知识 | 共识基线（双方其实都同意什么）+ 孤证区（不该被当成规律的那一条） |
| 个性化知识发现 / 观点对照类 AI 应用原型 | 站边后的信念推演即个性化输出：同一份数据，不同立场的人看到不同的"你必须站哪边"和不同的代价 |

## 诚实的边界

- 内置数据集是**示例**，依据公开讨论重构，不是知乎原文引用。
- 不做抓取：知乎有反爬，且这个产品的定位是"你已经有一堆文字，我帮你读懂它"。
- 只有中文，没做多语言（赛道方向里的"跨语言"没有覆盖）。
- 互斥表人工维护，长尾标签会漏，遇到表外标签只按字面重叠判断。
- 规模：演示集是 5–6 条回答，不是 500 条的压测。
