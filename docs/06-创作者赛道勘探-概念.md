# 赛道勘探 Field Survey —— 给知乎新创作者的选题地形图

> 一句话：**它不告诉你什么会火，它告诉你这个领域的话说到哪儿了、哪里还空着。**

配套产品《歧见 Fault Lines》见 `docs/01-产品概念.md`。两者共用同一个引擎，是两个视角。

---

## 一、问题：新创作者真正的困难不是"没灵感"

一个刚进知乎的人，打开物理学话题，看到几千个问题、上万条回答。他手里的困惑是三个，而且都很具体：

1. **这个领域到底在争什么？** 哪些是已经定论的基础（说了没人理），哪些是还在被反复争夺的活断层（还有读者在等一个说法）。
2. **我能占哪个位？** 不是"我该写什么"，是"我说的话，在这个领域里算不算重复"。
3. **有哪些话，读者在问，但没人好好答？** 这是最容易出成绩、也最看不见的地方。

现有工具回答的是"什么内容火"（流量预测），而创作者真正缺的是**"这个领域的论述供给长什么样"**。

这两件事不一样：火不火取决于推荐算法，你没法控制；说不说得上话取决于这个位置有没有人，你能看见。

## 二、核心洞察：赛道不是流量池，是一张论述供给图

把任何一个细分领域（比如"量子力学中的测量问题"），看成一块被反复开采的矿：

| 位置 | 在领域里的含义 | 对新创作者意味着 |
|---|---|---|
| **共识基线** | 大多数人已经同意的基础事实 | 入场门槛：不懂这些，写什么都会被指错。但只写这些，没人会看 |
| **活断层** | 仍在被反复争夺的争点 | 有读者、有情绪、有对立面。**适合进攻**，代价是容易挨骂 |
| **孤证区** | 只有一个人在坚持、但没人认真反驳的观点 | 薄弱但有价值的角度。**适合重新论证**——它可能对，只是没被讲清楚 |
| **沉默的多数** | 读者反复在问、但没人为它写过像样回答的问题 | 空白位。**最适合新人**，因为没有竞争 |
| **头部垄断度** | 高赞是否集中在极少数答主 | 决定你是"进入一个开放领域"还是"挑战一座山" |

前四项，`歧见` 的引擎已经在算了（论点萃取 → 争点归并 → 断层判定 → 共识基线 → 孤证/沉默多数）。第五项需要真实接口数据（赞同数分布）。

**所以这不是新写一个产品，是给同一个引擎换一副眼镜。**

- 读者戴上：*这个争论为什么分成两半* → 断层图
- 创作者戴上：*这个领域哪里还能插进一句话* → 地形图

## 三、数据：分两层，绝不假装有

### A 层：粘贴即可（无 Key 也能跑）

把话题页下的若干高赞回答粘进来，和 `歧见` 现有的导入流程完全一样。

能算：共识基线、活断层、孤证、沉默的多数（需问题的标题列表）、论述重复度。
**算不了**：浏览量、关注数、赞同分布。界面上必须如实标注"未接入接口，本图只反映所粘贴文本的论述结构"。

### B 层：知乎开放平台（有 Access Secret 时）

`developer.zhihu.com`，`Authorization: Bearer <secret>` + `X-Request-Timestamp`（秒级）。已核实的端点：

| 用途 | 端点 |
|---|---|
| 站内搜索（找细分领域下的问题） | `GET /api/v1/content/zhihu_search` |
| 热榜（判断领域是否正在被关注） | `GET /api/v1/content/hot_list` |
| 直答（生成领域综述/术语表） | `POST /v1/chat/completions` |
| OAuth 后的创作收藏数据 | OAuth 流程 + 账号端点 |

可获得的量化字段：问题的 **回答数 / 关注数 / 浏览数**，回答的 **赞同数 / 评论数 / 收藏数**，热榜的 **热度 / 名次**。

由这些能诚实算出：

- **需求供给比** = 关注数 ÷ 回答数（高：很多人想看但没人写 → 空白位）
- **头部垄断度** = 前 5 条回答赞同数 ÷ 全部回答赞同数（高：山已经被占了）
- **回答密度** = 平均每问回答数（高：红海，进去就沉）
- **冷热趋势** = 该领域问题在热榜的出现频次

### 明确不做的

- **不预测流量、不预测爆款、不估算收益。** 我们没有推荐算法的权重，任何"这样写能涨 5000 粉"都是编的。
- 不抓取（知乎直连 403），只走官方接口或用户粘贴。
- 不替代人的判断：它给的是"位置在哪"，不是"你该去哪个"。选哪个位取决于这个人自己会什么、愿意承担什么。

## 四、输出：一张地形图 + 三个建议位

对用户选定的细分领域，输出：

```
赛道：量子力学中的测量问题
─────────────────────────────
基础共识 3 条        —— 入场必读，写这些没人看
活断层 2 个          —— 还有人在争："退相干是不是已经解决了测量问题"
孤证 1 条            —— 只有一个答主坚持："多世界解释被误读了"
沉默问题 4 个        —— 高关注、低回答："为什么观测会改变结果" 等
头部垄断度 72%       —— 前 5 条回答吃掉七成赞同，硬骨头
─────────────────────────────
三个位：
 保守位  把共识基线讲得比现有回答更清楚（门槛低、天花板也低）
 进攻位  站进活断层的一侧，把另一侧的论据也摆出来（有观众、会挨骂）
 空白位  回答那 4 个沉默问题（无竞争、无人验证，成败自负）
```

每个位都附**代价**，不是只给好处——这是 `歧见` 一贯的做法：推演之后一定列代价。

## 五、与赛题的关系（赛道 01 社区 × 知识发现）

赛题写的是"用 AI 重构认知路径，帮助用户在纷繁信息中理解观点、梳理逻辑、发掘有效知识"。

一个新手进入陌生领域，正是"认知路径"最陡的一段：他需要知道这个领域的知识**结构**（哪些是地基、哪些是活跃争论），而不只是知识点。

- 依托社区内容资产 ✔（回答文本 + 接口元数据）
- 观点对照、信息过滤 ✔（断层与孤证）
- 面向学习者的知识整理与路径规划 ✔（三个位就是三条进入路径）

## 六、诚实边界

1. **没有接口 Key 时，本产品不产生任何流量数字。** 界面必须标注，不能拿"论述结构"冒充"赛道热度"。
2. "沉默的多数"依赖问题标题列表，纯粘贴模式下需要用户额外提供一批问题，否则这一栏是空的——空着也要显示为空，不能编。
3. 断言过的"孤证""空白位"只是候选，不是保证。一个没人写的问题也可能是因为它没价值。
4. 头部垄断度需要赞同数；没有 Key 时这一栏显示"未接入"。
5. 领域切分靠关键词，中文细分领域（"凝聚态物理"vs"固体物理"）容易混，需要人复核。
