## 四、推上 GitHub Pages（约 20 分钟）

### 4.1 前置

需要：一个 GitHub 账号、已装 git（本机 `git version 2.56.0` 已就绪）。

### 4.2 命令（在本机执行，把 `<你的用户名>` 换成你的）

```bash
# 1) 在 GitHub 网页上新建一个空仓库，名字随意，例如 qijian-fault-lines
#    不要勾选 "Add a README"（会与推送冲突）

# 2) 进入已组装好的站点目录
cd "D:/ai黑客松/build/pages"

# 3) 初始化并推送
git init
git add -A
git commit -m "歧见 Fault Lines · 知乎 S3 湾区共创季 赛道01"
git branch -M main
git remote add origin https://github.com/<你的用户名>/qijian-fault-lines.git
git push -u origin main

# 4) 打开仓库 Settings → Pages
#    Source 选 "Deploy from a branch"
#    Branch 选 main，目录选 / (root)，Save

# 5) 等 1–2 分钟，访问：
#    https://<你的用户名>.github.io/qijian-fault-lines/
```

### 4.3 推送后必须自查的三件事

1. 首页能打开，顶部下拉能切四个示例集（含湾区跨境卖家那集）。
2. 点「导入回答」，贴三段文字，点「生成断层图」→ 应出现断层图（走规则引擎，约 0.2 秒）。
3. 点任一条裂缝 → 选边 → 出现「信念推演」。若这三步都对，核心功能在公网可用。

> 公网版**没有**本机代理，所以「从知乎直接拉真问题」会提示需要 `node server.mjs`。
> 这是有意的降级，不是 bug——静态站点无法安全地持有你的 Access Secret。

### 4.4 以后每次改代码怎么更新

```bash
cd "D:/ai黑客松"
npm run build && node tools/pages.mjs        # 重新生成 build/pages
cd build/pages && git add -A && git commit -m "更新" && git push
```

## 五、最省事的一条路（已为你准备好脚本）

`build/pages` 已经是一个独立的 git 仓库（分支 `main`，一次提交，含 `index.html`、`docs/`、两个视频、联络表、字幕、`.nojekyll`）。你只需要：

1. 在 GitHub 上新建一个**空仓库**（不要勾 README / .gitignore / license）。
2. 在本项目根目录执行（把地址换成你自己的）：

```bat
push-to-github.bat https://github.com/<你的用户名>/qijian-fault-lines.git
```

3. 打开该仓库 → Settings → Pages → Source 选 `Deploy from a branch` → Branch 选 `main` / `(root)` → Save。
4. 等约 1 分钟，访问 `https://<你的用户名>.github.io/qijian-fault-lines/`。

`push-to-github.bat` 只是一个把上面三行命令包起来的批处理；它不保存任何凭证，认证由 Git 自己弹窗处理。

> 注意：`build/pages` 是独立仓库（外层 `.gitignore` 忽略了 `build/`），所以推送它不会带动主仓库，也不会把 23 MB 的工程历史推上去。

## 六、如果想让评委在公网也能用真模型

静态 Pages 没有后端，判委会看到「静态演示版：内置示例可直接浏览；导入分析走规则引擎」。这条路径在界面上是**如实标注**的，不会假装有模型。

真要给评委真模型，只有两条路：

- **知乎 AiWorks**（守则里明确推荐的一站式方案，适合「前端 + Node 后端、不写数据库」的项目）：把本仓库推上去，环境变量填 `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL`，平台会注入 `PORT`，服务端已按 `0.0.0.0` 监听。部署后跑 `curl https://<域名>/api/health` 应返回 `{"ok":true,"llm":{"enabled":true,...}}`。
- **云主机 + nginx 反代**：`node server.mjs` 常驻，反代时必须透传 `X-Forwarded-For`，否则「每 IP 每小时 N 次」的额度限流会把所有访问算成同一个 IP。

两条路都需要一个你自己的模型 Key（DeepSeek / 通义 / 智谱 / Moonshot 都行，改 `LLM_BASE_URL` 就能切）。
